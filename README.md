# olto-media

Stockage public des visuels d'Olto (@olto.media) pour la programmation dans Metricool.

- `posts/AAAA-MM-JJ-slug/` : images (01.jpg…) ou vidéo (reel.mp4) d'un post validé dans le QG.
- `stories/AAAA-MM-JJ/` : stories du soir (top5.jpg, mot.jpg) validées dans le QG.
- `render/` : moteur de rendu de la charte Olto (`python3 render/render.py story|post <json> <dossier>`).

Rien n'est déposé ici sans la validation d'Emeric dans le QG.
